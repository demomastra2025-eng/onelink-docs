# Agent Skill And Documentation Coverage

Status: current operational map for OneLink Hermes agents.

Purpose: keep every major project direction and product-functional area discoverable through both:

- a Hermes skill under `/root/.hermes/shared-skills/onelink`

## Audit Command

Use this lightweight check after changing the coverage map, docs, or shared skills:

```bash
python3 - <<'PY'
from pathlib import Path
import yaml
root = Path('/root/.hermes/shared-skills/onelink')
for p in sorted(root.glob('*/SKILL.md')):
    text = p.read_text()
    assert text.startswith('---'), p
    data = yaml.safe_load(text.split('---', 2)[1]) or {}
    assert data.get('name'), p
    assert data.get('description'), p
print('skills ok')
PY

python3 -m json.tool /root/crafty/onelink/onelink-docs/docs.json >/dev/null
```
