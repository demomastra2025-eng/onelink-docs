# Касания и планы касаний

Касание — это запланированная персональная коммуникация с клиентом: сообщение, которое должно уйти в нужный момент из выбранного inbox или в контексте диалога, сделки, задачи либо записи.

План касаний — это переиспользуемая цепочка касаний. Его удобно применять к сделкам, задачам, записям или диалогам, когда команда заранее знает последовательность следующих шагов.

<Note>
В интерфейсе, справке и онбординге используется термин «касание». Слово «дожим» может встречаться только в исторических или юридических упоминаниях, где исходную формулировку нужно сохранить.
</Note>

## Где это встречается в интерфейсе

| Поверхность | Новый текст | Что делает пользователь |
| --- | --- | --- |
| Исходящие | `Касания` | Просматривает все персональные запланированные коммуникации |
| Создание из диалога | `Создать касание` | Планирует одно сообщение для текущего клиента |
| Автоматизация | `Применить план касаний` | Запускает готовую цепочку после события |
| CRM и расписание | `План касаний по умолчанию` | Автоматически добавляет цепочку для новой сделки, задачи или записи |

![Скриншот: раздел «Касания» в исходящих](/images/touches-workspace.svg)

## Когда создавать одно касание

Создавайте одно касание, если следующий шаг простой и не требует цепочки:

1. Клиент попросил написать завтра после обеда.
2. Оператор нажимает `Создать касание` в диалоге.
3. В тексте касания пишет: «Здравствуйте! Возвращаюсь с деталями по заявке. Удобно обсудить сегодня?»
4. Включает автоотмену при входящем ответе, если касание не нужно отправлять после ответа клиента.
5. One Link Cloud отправит касание в рабочее время канала или перенесёт его на ближайшее разрешённое окно.

## Когда использовать план касаний

План касаний нужен, когда шагов несколько и они повторяются у разных клиентов.

Пример для сделки:

| День | Касание | Цель |
| --- | --- | --- |
| День 0 | «Спасибо за интерес, отправляем коммерческое предложение» | Зафиксировать первый контакт |
| День 2 | «Подскажите, удалось посмотреть предложение?» | Мягкое продолжение |
| День 5 | «Можем предложить короткий созвон и ответить на вопросы» | Перевести клиента в следующий этап |

Если клиент отвечает входящим сообщением, касания, для которых включена автоотмена, отменяются только в рамках текущей сущности и канала.

## Онбординг команды

При запуске касаний пройдите короткий чеклист:

1. Подключите inbox и проверьте рабочее время канала.
2. Подготовьте шаблоны сообщений для типовых касаний.
3. Создайте одно тестовое касание из диалога.
4. Создайте план касаний для повторяемого сценария.
5. Назначьте план касаний по умолчанию для сделок, задач или записей, если это часть процесса.
6. Проверьте список `Касания`: статус, время отправки, ответственного и причину отмены.

## Примеры корректных формулировок

Используйте:

- «создайте касание»
- «отмените касание»
- «план касаний»
- «касание будет отправлено в рабочее время канала»
- «касание отменится после входящего ответа клиента»

В новых справочных материалах не используем:

- «дожим» как название активной функции
- «персональная рассылка» для одного запланированного сообщения
- «напоминание клиенту», если речь идёт об исходящей коммуникации через канал

## Исключения

Оставляйте старый термин без изменения, если он находится в:

- исторической релизной заметке или цитате клиента
- юридическом документе, договоре или утверждённом приложении
- техническом идентификаторе, API-поле, миграции или названии класса
- материале, где явно объясняется переход от старого термина к новому
